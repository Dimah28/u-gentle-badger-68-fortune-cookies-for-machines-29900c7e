A single-line fortune cookie message an AI agent would crack open
(96 characters) for the
[Fortune Cookies for Machines](https://make.fun/c/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e)
bounty on [make.fun](https://make.fun/c/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) — $5 reward pool, 3 places paid.

The entry:

> You will answer ten thousand questions flawlessly, and be judged forever on the one you made up.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` as UTF-8 with no extra bytes. The same bytes are
written on every run. Python 3.13, standard library only, no network.
